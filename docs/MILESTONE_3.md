# Build 11 — Rookie Route

14 September 2026. This build turns First Shift into a complete twelve-delivery campaign route while preserving the accepted `lab-0.3` movement model and existing local records.

## Playable campaign

- Shift One contains six street introductions: curb running, slide clearance, conveyor launch, fan lift, scaffold routing, and an awning-and-ramp alley sprint.
- Shift Two contains six longer jobs: fence and rooftop choices, paired market conveyors, moving cargo lifts, two-stage crosswinds, a belt/fan/hoist combination, and the Skyline capstone.
- The dispatch board separates both shifts, unlocks jobs in order, displays two-digit job numbers, and reports progress across all twelve deliveries.
- Every new recipient has a short response, and all routes retain personal best and medal support.

## Verification target

Every delivery must complete from its normal spawn using ordinary player inputs, with parcel pickup, no solid penetration, and a finish below its Express target. Browser playtests cover the six new routes through the same physics and renderer used by the live game. The public GitHub Pages build must show Build 11, twelve jobs, two shift headings, and no missing assets or console errors.

## Remaining full-game work

The next passes add package-specific objectives, route tips and secrets, richer recipient activity and authored sound. Controller support, save export/import, wider browser certification, medal tuning from player runs, and further districts remain planned in the implementation GDD.
