# Build 05 — Special Delivery

Presentation-only pass requested after the First Shift campaign. The visual direction is a warm illustrated neighbourhood courier company: cream paper, burnt orange, sage and dark teal. Everything is drawn locally in CSS and Canvas without fonts, images or other network dependencies.

- Dispatch cards styled as printed job slips, with postal edging and a circular company stamp.
- Three parallax scenery layers, shop signs/awnings, rooftop water tanks, clouds and a construction crane.
- Rounded courier with cream helmet, orange jacket, scarf, dark trousers and running trainers. Crouching follows the existing collider height.
- Strong cream/dark edges on physical platforms, brick faces, marked teal fan volumes and green recipient doors.
- Instructions use cream panels to remain readable against the scenery.

No physics, collision shapes, timing targets or save formats changed. Decorative shopfronts are background scenery; only level-defined platforms are solid. Existing 43 regressions pass. Browser checks cover the dispatch board, street scene, full machinery input replay, recipient view and console errors. Input replay verification does not represent human feel testing.
